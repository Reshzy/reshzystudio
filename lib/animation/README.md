# Animation

Motion presets and helpers consuming design motion tokens.

## Contents

- `tokens.ts` — duration, easing, and stagger values mirrored from design tokens
- `presets.ts` — reusable fade / reveal / hero / page variants and transitions
- `stagger.ts` — sequential delay helper for entrance choreography
- `interactions.ts` — shared Tailwind recipes for press, lift, link, chip, and field microinteractions
- `reduced-motion.ts` — preference helpers for accessible motion

Client wrappers live in `design-system/primitives/motion/`.
