# Composites

Components composed from primitives for repeated exhibition patterns.

- `ArtworkCard` — artwork preview with standard, featured, and compact variants
- `ArtworkTeaser` — thin standard-variant wrapper for existing call sites
- `ArtworkMeta` — category and year metadata line
- `ArtworkGrid` / `ArtworkGridItem` — organic gallery grid
- `CategoryBadge` — discipline label with optional count
- `EmptyState` — accessible empty result messaging
- `SectionHeading` — shared section eyebrow, title, and supporting copy
- `Timeline` / `TimelineItem` — editorial journey list
- `SkillCard`, `ValueCard`, `StatCard`, `TechBadge`, `CTASection`
