# USER JOURNEY

Version: 1.0

---

# Purpose

This document defines the emotional and experiential journey every visitor should experience while exploring the portfolio.

The website should not feel like a collection of pages.

It should feel like a carefully curated exhibition.

Each section exists to guide visitors from curiosity to admiration.

---

# Stage One

## Arrival

Duration

0–5 seconds

Objective

Capture attention immediately.

Requirements

• Large typography

• Minimal distractions

• Immediate visual identity

• Clear artistic direction

The visitor should instantly understand:

"This is an artist."

Do not overload the hero section.

Avoid long introductions.

---

# Stage Two

## Curiosity

Duration

5–15 seconds

Objective

Encourage scrolling.

Visitors should begin discovering featured artwork.

The artwork should create enough curiosity to continue exploring.

---

# Stage Three

## Discovery

Visitors begin exploring the collection.

Artwork becomes the focus.

The interface fades into the background.

Allow generous spacing.

Never overwhelm with too many images at once.

---

# Stage Four

## Immersion

The visitor spends time inside individual artwork pages.

This is where storytelling happens.

Each artwork should answer:

What is this?

Why was it created?

What inspired it?

How was it made?

---

# Stage Five

## Appreciation

Visitors begin recognizing consistency.

They notice:

Craftsmanship

Presentation

Typography

Motion

Attention to detail

This builds trust.

---

# Stage Six

## Connection

Only after visitors appreciate the work should they learn about Rodge.

The About section should feel personal but restrained.

The goal is understanding—not self-promotion.

---

# Stage Seven

## Action

Visitors may:

Browse more

View another artwork

Download a résumé (future)

Start a conversation

The action should feel natural.

Never force conversion.
