# NAVIGATION

Version: 1.0

---

# Philosophy

Navigation should never interrupt the exhibition.

Visitors should always know:

• Where they are

• Where they came from

• Where they can go next

without consciously thinking about it.

Navigation should disappear into the experience.

---

# Principles

Navigation should be:

Minimal

Predictable

Fast

Accessible

Consistent

---

# Primary Navigation

Home

About

These future pages should not exist until implemented.

---

# Logo

The logo always returns to Home.

Logo animation should be subtle.

Never rotate.

Never bounce.

---

# Sticky Navigation

Navigation remains visible while scrolling.

Use slight transparency.

Background blur only when necessary.

Do not reduce artwork visibility.

---

# Mobile Navigation

Use a full-screen overlay.

The menu should feel calm.

Avoid slide-out side drawers.

Navigation should feel like opening another page.

---

# Active States

Always indicate the current page.

Use typography and subtle color changes.

Avoid large indicators.

---

# Back Navigation
