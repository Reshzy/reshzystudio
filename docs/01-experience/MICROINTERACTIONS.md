# MICROINTERACTIONS

Version: 1.0

---

# Philosophy

Microinteractions create delight through subtlety.

Visitors should notice the experience—

not the animation itself.

---

# Buttons

Hover

Slight elevation.

Small scale.

Smooth transition.

Active

Small compression.

Release naturally.

---

# Links

Links should animate typography.

Avoid flashy effects.

Underline animation preferred.

---

# Cards

Slight lift.

Image movement.

Soft shadow adjustment.

Never dramatic.

---

# Gallery

Images slightly zoom.

Cursor changes.

Artwork title fades in.

No aggressive movement.

---

# Navigation

Current item transitions smoothly.

No snapping.

---

# Page Load

Content fades naturally.

Never pop into existence.

---

# Image Loading

Skeletons or subtle placeholders.

Avoid visible layout shifts.

---

# Cursor

Cursor expands over artwork.

Displays contextual labels:

View

Open

Next

Back

Never block artwork.

---

# Scroll Indicator

Minimal.

Disappears naturally.

Never loops endlessly.

---

# Contact

Inputs animate focus.

Labels remain readable.

Error messages feel calm.

---

# Forms

Validation appears immediately.

Never shake inputs.

Never flash red.

Explain the problem.

---

# Success

Success messages feel rewarding.

Not celebratory.

Avoid confetti.

Avoid fireworks.

This is a premium portfolio.

Not a mobile game.
