# SCROLL CHOREOGRAPHY

Version 1.0

---

# Philosophy

Scrolling should feel like walking through an exhibition.

Not browsing a catalog.

---

# Rhythm

Visual

↓

Whitespace

↓

Visual

↓

Whitespace

↓

Visual

This creates breathing room.

---

# Scroll Speed

Never lock scrolling.

Never hijack scrolling.

Use smooth scrolling responsibly.

The browser should always remain responsive.

---

# Reveals

Content enters naturally.

Never explode onto the screen.

Preferred animations

Fade

Translate

Scale

Mask Reveal

Avoid

Bounce

Spin

Elastic

Overly playful motion

---

# Parallax

Subtle only.

Parallax should support depth.

Not become the attraction.

---

# Section Timing

Visitors should comfortably consume each section before the next appears.

Avoid information overload.
