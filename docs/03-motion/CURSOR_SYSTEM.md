# CURSOR SYSTEM

Version: 1.0

---

# Philosophy

The cursor is part of the storytelling.

It should feel intelligent.

Not decorative.

---

# Default

Minimal circle.

Small.

Responsive.

Smooth interpolation.

---

# Hover States

Artwork

Cursor enlarges.

Displays:

View

---

Links

Cursor subtly expands.

Underline animation also appears.

---

Buttons

Cursor magnetically follows movement.

Very subtle.

---

Gallery

Cursor indicates:

Next

Previous

Open

depending on context.

---

# Motion

Cursor movement should lag slightly behind the mouse.

Never become sluggish.

Maintain responsiveness.

---

# Mobile

Disable entirely.

Touch already provides interaction.

---

# Accessibility

Allow users to disable the custom cursor.

Respect prefers-reduced-motion.
