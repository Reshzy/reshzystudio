# IMAGE ANIMATIONS

# Philosophy

Artwork deserves respectful presentation.

Animations should make images feel alive.

Never manipulated.

Hover

# Closing

Maintain continuity.

Smooth fade.

---

# Loading

Progressive image loading.

No layout shifts.

Rotate artwork.

Warp artwork.

Stretch artwork.

Artificially crop artwork.
