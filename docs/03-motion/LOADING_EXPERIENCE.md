# LOADING EXPERIENCE

Version: 1.0

---

# Philosophy

Loading is part of the experience.

Not an interruption.

---

# Initial Load

Elegant.

Minimal.

Typography preferred over spinners.

---

# Image Loading

Blur.

Fade.

Skeleton.

Never flashing placeholders.

---

# Route Loading

Shared transitions.

Avoid blank screens.

---

# Rule

Loading should reduce perceived waiting.

Not simply display progress.
