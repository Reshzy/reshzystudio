# SCROLL ANIMATIONS

Version: 1.0

---

# Philosophy

Scrolling is the primary interaction.

It should feel like revealing pages of a curated exhibition.

---

# Allowed

Fade

Translate

Mask Reveal

Image Scale

Opacity

Clip Path

Typography Reveal

---

# Avoid

Bounce

Rotate

Elastic

Physics jokes

Comic timing

---

# Reveal Direction

Prefer upward movement.

Avoid excessive horizontal motion.

---

# Section Reveal

Never animate every element individually.

Animate groups.

Create rhythm.

---

# Exit Animations

Allow previous content to disappear gracefully.

Avoid sudden disappearance.

---

# Rule

Scrolling should reward curiosity.
