# EASING CURVES

Version: 1.0

---

# Philosophy

Good easing feels invisible.

Poor easing feels artificial.

---

# Preferred

Ease Out

Ease In Out

Custom cubic-bezier

Spring only when appropriate.

---

# Avoid

Linear for UI animation.

Elastic.

Bounce.

Overshoot.

Unless specifically justified.

---

# Consistency

Reuse easing curves.

Avoid every animation having different timing.
