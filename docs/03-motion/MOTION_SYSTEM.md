# MOTION SYSTEM

Version: 1.0

---

# Purpose

Motion is one of the defining characteristics of this portfolio.

It should elevate the artwork—not distract from it.

The website should feel alive, calm, and responsive.

Visitors should notice the overall feeling rather than individual animations.

---

# Motion Philosophy

Motion exists to communicate.

Never animate for decoration alone.

Every animation must answer at least one of the following questions:

• What changed?

• Where should the user look?

• What is connected?

• What should happen next?

If none apply,

remove the animation.

---

# Characteristics

Motion should feel:

Elegant

Confident

Physical

Smooth

Responsive

Editorial

Never:

Playful

Cartoonish

Chaotic

Aggressive

Random

---

# Motion Hierarchy

Primary Motion

Major transitions.

Page changes.

Hero reveals.

Gallery openings.

---

Secondary Motion

Hover effects.

Cards.

Navigation.

Cursor.

---

Micro Motion

Buttons.

Links.

Inputs.

Loading.

Feedback.

---

Background Motion

Grain.

Light.

Ambient effects.

Should almost disappear.

---

# Movement

Everything should feel like it has weight.

Objects should never teleport.

Everything enters naturally.

Everything leaves naturally.

Momentum matters.

---

# Rule

Motion should support storytelling.

Not compete with storytelling.
