# PAGE TRANSITIONS

Version: 1.0

---

# Philosophy

Moving between pages should feel like walking into another room of the same exhibition.

Not opening a completely different website.

---

# Transition Style

Crossfade

Mask Reveal

Image Continuity

Shared Element

Typography Continuity

---

# Never Use

Flash cuts

Hard reload feeling

Spinning loaders

Random wipes

Overly cinematic effects

---

# Navigation

Every transition should preserve orientation.

Visitors should never wonder:

"Did the page reload?"

Instead they should feel:

"I'm continuing the experience."

---

# Artwork Pages

Artwork should remain the visual anchor.

Allow shared image transitions whenever possible.

---

# Timing

Fast enough to remain responsive.

Slow enough to feel intentional.

---

# Final Rule

Transitions should hide technical boundaries between pages.
