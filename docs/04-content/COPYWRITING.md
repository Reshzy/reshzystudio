# COPYWRITING

Version: 1.0

---

# Purpose

The portfolio should communicate through clarity rather than volume.

The writing exists to support the artwork.

Never compete with it.

---

# Voice

Editorial.

Thoughtful.

Minimal.

Professional.

Confident.

Never arrogant.

---

# Writing Principles

Write less.

Say more.

Avoid unnecessary adjectives.

Avoid clichés.

Avoid marketing language.

Avoid filler.

Every sentence should communicate value.

---

# Never Use

"I am passionate..."

"I've always loved..."

"Creative problem solver."

"Results-driven."

"Thinking outside the box."

"Hardworking."

"Dedicated."

These phrases communicate nothing.

---

# Instead

Describe the work.

Describe the process.

Describe the intention.

Describe the outcome.

---

# Paragraph Length

Prefer:

1–4 sentences.

Avoid long walls of text.

Whitespace improves readability.

---

# Headlines

Headlines should be short.

Strong.

Editorial.

Examples

Selected Work

Collection

Latest Pieces

Sketchbook

Archive

Studio

Instead of

My Projects

My Portfolio

Gallery

# Storytelling

Each artwork should answer:

What is this?

Why was it created?

How was it made?

What did I learn?

---

# Final Rule

If removing a sentence improves the page,

remove it.
