# Rodge Andru Portfolio

> "An online exhibition of creativity, craftsmanship, and thoughtful design."

---

## Overview

This repository contains the source code, documentation, design system, and creative direction for the official portfolio website of **Rodge Andru P. Viloria**.

Unlike a traditional portfolio, this project is designed as a curated digital exhibition where artwork, storytelling, interaction, and technology work together to create a memorable experience.

The website is both:

- A showcase of creative work
- A demonstration of design and frontend craftsmanship

Every decision, from typography to animation timing, is intentional.

---

## Project Goals

The website should:

- Present artwork beautifully
- Feel like a premium digital gallery
- Demonstrate attention to detail
- Leave a memorable impression
- Scale into a complete creative portfolio over time

Version 1 focuses on artwork.

Future versions introduce frontend projects, full-stack applications, creative coding, UI/UX case studies, and technical writing.
