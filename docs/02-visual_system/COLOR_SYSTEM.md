# COLOR SYSTEM

Version: 1.0

---

# Philosophy

Color should frame the artwork.

Not compete with it.

---

# Theme Support

Dark

Light

Both themes are first-class citizens.

Neither is an afterthought.

---

# Palette

Primary Background

Neutral

Primary Text

Neutral

Accent

Single brand color.

Used sparingly.

Success

Green.

Warning

Amber.

Error

Red.

---

# Accent Usage

Buttons

Links

Selections

Cursor

Never large backgrounds.

---

# Artwork

Never tint artwork.

Never overlay gradients.

Respect original colors.

---

# Contrast

Meet WCAG AA minimum.

AAA whenever practical.
