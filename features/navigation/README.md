# Navigation

Site navigation and wayfinding capability.

## Components

- `SiteHeader` — sticky primary navigation with logo, desktop links, theme toggle
- `MobileNav` — full-screen overlay menu for small viewports
- `NavLink` — active-state aware navigation link
- `SiteFooter` — secondary footer with contact/social links and copyright

Primary navigation is content-driven from `content/site/config.json`.
Footer never duplicates primary navigation.
